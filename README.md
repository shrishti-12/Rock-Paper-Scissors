# Rock Paper Scissors Game 🎮

A simple Rock-Paper-Scissors game built using **HTML**, **CSS**, and **JavaScript**. Play against the computer and test your luck!

## ✨ Features
- Classic Rock-Paper-Scissors game logic
- Interactive buttons for gameplay
- Dynamic result display
- Simple and clean UI

## 📂 Files Used
- `index.html` — Structure of the game
- `style.css` — Styling of the game UI
- `game.js` — Game logic and interactivity
- `rock.png`, `paper.png`, `scissors.png` — Images used for buttons or display
